## 🛠️ Tecnologias Utilizadas

- **TypeScript** — linguagem principal (arquivos `.ts` em `src/`)
- **JavaScript (Node.js)** — resultado da compilação TypeScript (arquivos `.js` em `dist/`)
- **Módulo `readline`** — nativo do Node.js, usado para entrada interativa no terminal
- **Programação Orientada a Objetos** — classes, herança, interfaces (exercícios 11–13)
- **Expressões Regulares** — usadas nos exercícios 08, 16 e 18
